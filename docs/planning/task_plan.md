# 研报文本自动生成 PPT 项目任务计划

## 项目目标

构建一个「研报文本 → 可视化 PowerPoint」自动生成系统。

输入：

- 上市公司研究报告文本
- Markdown 格式研报

输出：

- 结构完整的 PowerPoint 文件
- 自动生成图表和表格
- 使用固定 PPT 模板保持统一视觉风格


---
