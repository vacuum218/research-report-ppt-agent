# 验收标准与风险

## 验收标准

## 功能完整性

合格：

-   样例研报生成 PPT
-   PPT 可以正常打开

优秀：

-   支持复杂 Markdown
-   多级标题
-   表格解析

## 可视化准确率

合格：

准确率和召回率 \>=70%

优秀：

> =85%

## 数值准确性

要求：

图表数据必须来自原文。

禁止：

LLM 自行编造数字。

## 版式质量

检查：

-   无文字溢出
-   无图片遮挡
-   风格统一

## 工程质量

要求：

-   README
-   环境说明
-   单元测试
-   模块清晰

## 风险

### R1 LLM 幻觉

解决：

抽取后与原文核对。

### R2 PPT 排版异常

解决：

增加布局规则。

### R3 项目延期

解决：

任务顺延到 Week5-8。

### R4 数据不足

解决：

持续增加研报测试集。

### R5 接口不一致

解决：

提前冻结 JSON Schema。
