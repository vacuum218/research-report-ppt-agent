# 研报PPT自动生成项目 --- 项目上下文说明

## 项目目标

构建一个「研报文本 → 可视化 PowerPoint」自动生成系统。

输入： - 上市公司研究报告纯文本 - Markdown 格式研报文本

输出： - 结构完整的 PowerPoint 文件 - 保留研报核心信息 -
自动识别可视化内容 - 自动生成图表/表格 - 使用固定模板保持视觉一致

## 项目定位

参考 MemSlides 思路，但不是复刻。

MemSlides： - 输入论文 PDF - 具有用户风格记忆 - generate / revise /
template-induct 三阶段

本项目： - 输入研报文本 - 不做用户个性化风格学习 - 使用固定 PPT 模板 -
增加研报数值信息自动可视化能力

## 核心创新点

1.  文本理解
2.  幻灯片结构规划
3.  可视化信息定位
4.  自动图表生成
5.  模板化 PPT 渲染

## 开发原则

Codex 每次启动必须先阅读本目录所有文档。

实现任何功能前： 1. 明确属于哪个模块 2. 检查接口定义 3. 保持 JSON schema
稳定 4. 不破坏已有功能
