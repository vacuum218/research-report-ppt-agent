## 任务字段映射

| 任务表表述 | 正式 Schema 字段 | 说明 |
|---|---|---|
| slide title | `slides[].title` | 页面结论式标题 |
| slide type | `slides[].slide_type` | 页面业务主题，不表示模板布局 |
| summary | `slides[].key_message` | 页面单一核心结论 |
| bullet points | `slides[].bullet_points` | 支撑结论的要点 |
| source text / 原文引用 | `sources` + `slides[].source_refs` | 大纲保存来源目录和引用，不复制长原文 |
| visual candidates | `slides[].visual_candidates` | 只描述图表/表格意图，不包含实际数据 |
